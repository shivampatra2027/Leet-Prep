# Leet.IO Backend

> Backend API for Leet.IO coding platform

## About

A Node.js backend service for managing coding problems and user authentication.

## Features

- User authentication system
- Problem database management
- Company-based filtering
- Premium user support
- RESTful API architecture

## Tech Stack

Built with Node.js, Express, and MongoDB. Includes authentication, security middleware, and caching layers.

## Setup

Required dependencies:

- Node.js
- MongoDB
- Environment configuration

Install and configure according to your deployment environment.
